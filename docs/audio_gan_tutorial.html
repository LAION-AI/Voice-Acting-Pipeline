1. What is a GAN? (The Basics)

A Generative Adversarial Network (GAN) is a machine learning framework where two neural networks compete against each other to produce realistic outputs. Think of it as an art forger (the Generator) trying to create convincing fake paintings, while an art critic (the Discriminator) tries to distinguish fakes from real masterpieces.

The Two Players

Generator (G) — Takes random noise or a conditioning input (like a mel spectrogram) and produces a synthetic output (like an audio waveform). Its goal: fool the discriminator into thinking the output is real.
Discriminator (D) — Takes both real and generated samples and outputs a score indicating how "real" each sample looks. Its goal: correctly classify real vs. fake.
┌─────────────┐ Mel Spectrogram──▶│ Generator │──▶ Fake Waveform ──┐ │ (G) │ │ └─────────────┘ ▼ ┌──────────────┐ Real Waveform ──────────────▶│Discriminator │──▶ Real/Fake Score │ (D) │ └──────────────┘ │ Gradient feedback ◄─────────────────┘ (D tells G how to improve)

The Training Loop

Training alternates between two steps:

  1. Train D: Show D real audio (label: "real") and G's fake audio (label: "fake"). D learns to tell them apart.
  2. Train G: Generate fake audio and ask D to score it. G's loss is based on how well it fooled D. G learns to make more convincing fakes.

At convergence, G produces outputs so realistic that D can't tell them from real data. The discriminator's output approaches 0.5 — maximum uncertainty — because every sample looks equally plausible.

Key Insight: The discriminator is not used at inference time. It's a "training wheel" that teaches the generator to produce realistic outputs. Once training is done, only G is deployed.

2. Audio Representations: How Computers See Sound

Raw Waveform

Audio is stored as a sequence of amplitude values sampled at regular intervals. Common sample rates:

Sample RateUse CaseSamples per Second
16 kHzSpeech (telephony, TTS)16,000
22.05 kHzStandard TTS22,050
24 kHzHigh-quality speech24,000
44.1 kHzMusic, universal audio44,100
48 kHzProfessional audio48,000

At 16 kHz, one second of audio = 16,000 floating-point numbers. A 10-second clip = 160,000 values. This is what the generator outputs.

Mel Spectrogram

A mel spectrogram is a 2D representation of sound: time on one axis, frequency on the other, with pixel brightness indicating energy. The "mel" scale warps frequencies to match human hearing (we're more sensitive to differences between low pitches than high pitches).

How it's computed: Short-Time Fourier Transform (STFT) decomposes the waveform into overlapping windows, applies FFT to each, maps the frequency bins onto the mel scale, and takes the log of the magnitudes.

Key parameters that define a mel spectrogram:

ParameterWhat It DoesTypical Values
n_fftFFT window size in samples. Larger = better frequency resolution, worse time resolution1024
hop_lengthStep between consecutive windows in samples. Controls time resolution256
n_melsNumber of mel frequency bins. More bins = finer frequency detail80 – 128
f_minLowest frequency captured (Hz)0
f_maxHighest frequency captured (Hz). Usually sr/2 (Nyquist)8000 – 22050
sample_rateSample rate of the input audio16000 – 44100
Why mel spectrograms? They compress a 16,000-dimensional waveform second into an ~62×80 matrix (~5,000 values) while preserving perceptually relevant information. This makes them ideal as an intermediate representation for TTS systems.

Latent Representations

Modern audio codecs like EnCodec, SoundStream, and the LTX-2.3 Audio VAE compress audio even further into a low-dimensional latent space using a learned encoder. The latent vectors are ~8× to ~160× smaller than mel spectrograms. A decoder reconstructs mel spectrograms from these latents, and then a vocoder converts the mel spectrogram to a waveform.

3. The Vocoder: From Spectrograms to Waveforms

A vocoder (voice coder) is a model that converts a mel spectrogram back into an audio waveform. This is the final stage of a text-to-speech pipeline:

Text ──▶ Language Model ──▶ Latent ──▶ VAE Decoder ──▶ Mel Spectrogram ──▶ Vocoder ──▶ Waveform ▲ This is what we're training

Why is this hard?

A mel spectrogram contains ~5,000 values per second. The output waveform contains ~16,000–48,000 values per second. The vocoder must invent all the missing detail — phase information, fine harmonic structure, transients — that was lost during the mel compression. This is fundamentally an underdetermined problem (many waveforms produce the same mel spectrogram).

4. HiFi-GAN & BigVGAN Architecture

HiFi-GAN Generator (2020)

The foundational architecture used by BigVGAN. It's a fully convolutional upsampling network:

Mel Spectrogram (80 × T) │ ▼ ┌──────────────────┐ │ Conv1D (pre-net) │ Project mel channels → 512 channels └────────┬─────────┘ │ ┌────────▼─────────┐ │ TransposedConv1D │ Upsample 8× (kernel=16, stride=8) │ + MRF Block │ Multi-Receptive-Field Fusion └────────┬─────────┘ ┌────────▼─────────┐ │ TransposedConv1D │ Upsample 8× (kernel=16, stride=8) │ + MRF Block │ → now 64× upsampled └────────┬─────────┘ ┌────────▼─────────┐ │ TransposedConv1D │ Upsample 2× (kernel=4, stride=2) │ + MRF Block │ → 128× └────────┬─────────┘ ┌────────▼─────────┐ │ TransposedConv1D │ Upsample 2× (kernel=4, stride=2) │ + MRF Block │ → 256× upsampled (= hop_length) └────────┬─────────┘ │ ┌────────▼─────────┐ │ Conv1D (post-net) │ Project to 1 channel │ + tanh │ Clamp to [-1, 1] └──────────────────┘ │ ▼ Waveform (1 × T×256)

The Multi-Receptive-Field Fusion (MRF) module processes features through parallel residual blocks with different kernel sizes (3, 7, 11) and dilation patterns, then averages their outputs. This captures both fine-grained detail and broader patterns.

BigVGAN: What Changed?

1. Snake Activation Function

Standard activations (ReLU, LeakyReLU) have no inherent understanding of periodicity. Audio is fundamentally periodic (speech = vocal cord vibrations + resonances). The Snake activation adds a periodic inductive bias:

Snake(x) = x + (1/α) · sin²(α · x)

Where α is a learnable parameter that controls the frequency. Each channel learns its own frequency. The identity term x ensures the function is monotonic (always increasing), which makes optimization tractable.

SnakeBeta (used in BigVGAN v2) adds a separate trainable parameter β for amplitude control:

SnakeBeta(x) = x + (1/β) · sin²(α · x)

Both α and β are parameterized in log-scale for numerical stability.

2. Anti-Aliased Multi-Periodicity Composition (AMP)

Applying a nonlinear activation (like Snake) to an upsampled signal creates high-frequency harmonics that can alias back into the audible range, producing metallic/buzzing artifacts. The AMP module prevents this:

Input signal │ ▼ Upsample 2× (insert zeros + low-pass filter) │ ▼ Apply Snake activation (creates harmonics above Nyquist) │ ▼ Low-pass filter (remove harmonics above Nyquist) │ ▼ Downsample 2× back to original rate │ ▼ Clean, alias-free activated signal

The low-pass filters use Kaiser-windowed sinc filters, a classical signal processing design borrowed from StyleGAN3.

5. Discriminator Architectures: Teaching a Critic

The discriminator is the "teacher" that provides gradient signal to the generator. Its design profoundly affects what the generator learns. Audio GANs typically use multiple sub-discriminators, each specializing in a different aspect of audio quality.

Multi-Period Discriminator (MPD)

Introduced in HiFi-GAN. Exploits the periodic nature of audio by reshaping the 1D waveform into 2D tensors with different periods:

Waveform: [s1, s2, s3, s4, s5, s6, s7, s8, s9, s10, s11, s12, ...] Period=2: │s1 s2│ Period=3: │s1 s2 s3│ Period=5: │s1 s2 s3 s4 s5│ │s3 s4│ │s4 s5 s6│ │s6 s7 s8 s9 s10│ │s5 s6│ │s7 s8 s9│ │... │ │... │ │... │ Standard periods: {2, 3, 5, 7, 11} (prime numbers to avoid overlap) Each 2D tensor → 2D CNN → scalar score

This captures harmonic patterns at different fundamental frequencies. A voice at 200 Hz has period = sample_rate/200 = 80 samples at 16 kHz. By checking primes, MPD covers many harmonic relationships.

Multi-Scale Discriminator (MSD)

Three 1D CNNs operating at different time scales:

  • Scale 1: Raw waveform (full detail)
  • Scale 2: 2× average-pooled (half resolution)
  • Scale 3: 4× average-pooled (quarter resolution)

Captures both fine-grained texture (Scale 1) and broader structure (Scale 3).

Multi-Resolution Discriminator (MRD)

From UnivNet. Operates on linear spectrograms (not waveforms) computed with different STFT parameters. Used in BigVGAN to replace MSD because spectral representations make frequency-domain artifacts more visible.

STFT Discriminator (What We Use)

Our custom Multi-Resolution STFT Discriminator operates on log-magnitude + phase spectrograms via 2D convolutions. This was the key breakthrough in our experiments:

Waveform │ ├──▶ STFT(n_fft=256, hop=64) ──▶ [log_mag + phase] ──▶ 2D CNN ──▶ Score₁ ├──▶ STFT(n_fft=512, hop=128) ──▶ [log_mag + phase] ──▶ 2D CNN ──▶ Score₂ ├──▶ STFT(n_fft=1024, hop=256) ──▶ [log_mag + phase] ──▶ 2D CNN ──▶ Score₃ └──▶ STFT(n_fft=2048, hop=512) ──▶ [log_mag + phase] ──▶ 2D CNN ──▶ Score₄ │ Total D loss = Σ all scores
Why STFT discriminators work for our task: The metallic artifacts from BigVGAN's Snake activations are nearly invisible in the raw waveform (amplitude differences <0.1%) but are clearly visible as extra harmonic lines in the spectrogram. An STFT discriminator sees these artifacts 10–100× more clearly than waveform-based discriminators (MPD/MSD).

MS-SB-CQTD (BigVGAN v2)

Multi-Scale Sub-Band Constant-Q Transform Discriminator. Uses CQT instead of STFT. CQT provides logarithmic frequency resolution (like human hearing), giving better pitch accuracy and harmonic tracking. Published at ICASSP 2024.

6. Loss Functions: How GANs Learn

Audio GANs use a combination of losses. The total generator loss looks like:

LG = Ladv + λfm · LFM + λmel · Lmel [+ λstft · LSTFT]

Adversarial Loss (Ladv)

The core GAN signal. Two main formulations:

LSGAN (Least Squares GAN)

Used in HiFi-GAN, BigVGAN, and our experiments.

LD = E[(D(real) - 1)² + D(fake)²]
LG = E[(D(fake) - 1)²]

The discriminator wants D(real)→1 and D(fake)→0. The generator wants D(fake)→1. The L2 penalty provides smooth gradients everywhere (unlike vanilla GAN which saturates). With K sub-discriminators, losses are summed.

Hinge Loss

Used in Vocos. Clips the gradient when D is already confident:

LD = E[max(0, 1 - D(real))] + E[max(0, 1 + D(fake))]
LG = -E[D(fake)]

Hinge loss can be more aggressive — D gets no further reward for pushing scores beyond ±1.

Feature Matching Loss (LFM)

Compares intermediate features of the discriminator for real and fake audio:

LFM = Σl ||D(l)(real) - D(l)(fake)||1

This stabilizes training by giving the generator a "perceptual" learning signal from the discriminator's learned features, rather than just the final scalar score. It prevents the generator from overtraining against the current discriminator state. Standard weight: λfm = 2.

Mel-Spectrogram L1 Loss (Lmel)

Direct reconstruction loss between mel spectrograms of real and generated audio:

Lmel = ||log mel(real) - log mel(fake)||1

This is typically the strongest learning signal, with weight λmel = 45 in HiFi-GAN and BigVGAN. It ensures the generated audio has roughly correct energy distribution across frequencies. In our training, we use a multi-resolution variant with 4 mel configs.

Multi-Resolution STFT Loss (LSTFT)

Combines spectral convergence and log-magnitude L1 at multiple STFT resolutions:

LSTFT = (1/N) Σi [||STFTi(real) - STFTi(fake)||F / ||STFTi(real)||F + ||log|STFTi(real)| - log|STFTi(fake)|||1]

We use this with weight λstft = 5 in our training.

Loss Weight Balance: In all major vocoders (HiFi-GAN, BigVGAN, our setup), the reconstruction losses (mel, STFT) dominate with combined weight ~50, while adversarial + feature matching have weight ~5. The GAN provides "sharpening" and "detail" while reconstruction losses ensure correctness.

What Each Hyperparameter Controls

G Learning Rate — How fast the generator adapts. Too high: training instability, divergent loss. Too low: slow convergence. For fine-tuning, use 0.5–1× the from-scratch rate.
D Learning Rate — How fast the discriminator adapts. Must be balanced with G LR. If D learns too fast, it gives vanishing gradients to G ("D too strong"). If too slow, it provides no useful signal ("D collapse").
D/G Update Ratio — How many D steps per G step. 1:1 is standard. We use 5:1 because our STFT discriminator is small (4.6M params) relative to the generator (115M), so it needs more updates to keep up.
Batch Size — Larger batches reduce gradient noise and mode collapse risk. BigVGAN doubled from 16 to 32 specifically for stability. We use 6–12 due to VRAM constraints.
Gradient Clipping — Caps the maximum gradient magnitude. Essential in BigVGAN because the anti-aliased activation can amplify gradients. We use aggressive clipping (5.0) because our setup is more sensitive to gradient spikes.
Spectral Normalization — Constrains the Lipschitz constant of D's layers by normalizing weight matrices by their largest singular value. Prevents D from becoming too "sharp" (high capacity but unstable). However, it can also prevent D from learning subtle differences.
R1 Gradient Penalty — Penalizes the gradient of D w.r.t. real data: R1 = λ · E[||∇D(real)||²]. Regularizes D to be "smooth." We found R1=10 was too strong for our fine-tuning task — it prevented D from learning.

The Balance Dance

GAN training is a dynamic equilibrium between two opposing forces. Think of it as a seesaw:

D too weak (gap < 0.1) D too strong (gap > 0.95) ┌─────────────────────┐ ┌─────────────────────┐ │ D gives no useful │ │ D is perfect, G gets│ │ gradient to G. │ │ no useful gradient │ │ G improves only via │ │ (vanishing gradient)│ │ mel/STFT losses. │ │ g_adv plateaus at │ │ GAN adds nothing. │ │ maximum value. │ └─────────────────────┘ └─────────────────────┘ ┌───────────────┐ │ SWEET SPOT │ │ gap: 0.3-0.8 │ │ D provides │ │ useful signal │ │ G can still │ │ improve │ └───────────────┘
Important nuance: When fine-tuning (not training from scratch), a gap near 1.0 can still be fine — if mel loss is still decreasing. In our experiments, D quickly learns to near-perfect discrimination (gap > 0.95) because our generated audio is already very close to real audio. The G's main learning signal comes from mel/STFT reconstruction losses, with the GAN adding subtle sharpening.

9. Failure Modes: When Things Go Wrong

Discriminator Collapse (D Too Weak)

Symptoms: D(real) ≈ D(fake) ≈ 0.5, gap ≈ 0, d_loss constant at maximum value (e.g., 4.0 for 8 LSGAN sub-discriminators). The discriminator outputs ~0.5 for everything — maximum confusion.

Root causes:
  • Real and fake audio too similar for D to distinguish (common in fine-tuning)
  • R1 gradient penalty too high (suppresses D's ability to develop features)
  • D learning rate too low
  • Spectral normalization too restrictive for the signal difference
  • D operating in wrong domain (waveform-domain D can't see spectral artifacts)
Fixes:
  • Switch to spectral-domain discriminator (STFT, CQT)
  • Remove or reduce R1 penalty
  • Increase D learning rate
  • Increase D/G update ratio (give D more steps to learn)
  • Remove spectral normalization (carefully — may destabilize)

This was our central challenge. The original waveform discriminators (MPD+MSD with 8 sub-discriminators) were stuck at gap ≈ 0.001 because the BigVGAN-generated audio was >99% identical to real audio at the waveform level. The metallic artifacts were invisible to waveform-domain D but clearly visible in spectrograms.

Mode Collapse (G Too Narrow)

Symptoms: G produces similar outputs regardless of input. Audio sounds "frozen" or "buzzy." Multiple different mel inputs yield near-identical waveforms.

Root causes:
  • D too strong (G learns a single "safe" output that fools D)
  • Insufficient training data diversity
  • Too many discriminators (BemaGANv2 found 3 simultaneous discriminators cause collapse)
  • Learning rate too high
Fixes:
  • Reduce D learning rate or freeze D layers
  • Increase batch size (BigVGAN doubled to 32 for this reason)
  • Add reconstruction losses (mel L1, STFT) to anchor G's output
  • Data augmentation

Generator Explosion

Symptoms: mel loss suddenly jumps from ~0.3 to >1.0 or more. G gradients spike. Generated audio becomes noise.

Root causes:
  • Removing spectral normalization without stabilization (we saw mel: 0.3 → 8.5)
  • Gradient explosion through deep computation graphs (decoder → vocoder chains)
  • Learning rate too high after warmup
Fixes:
  • Gradient clipping (we use max_norm=5.0)
  • Lower G learning rate
  • Reduce adversarial weight
  • Use spectral normalization on D (even if it limits D capacity, stability is more important)

Metallic / Ringing Artifacts

Symptoms: Audio sounds "tinny," "metallic," or has a shimmer/ringing quality, especially at high frequencies.

Root causes:
  • Aliasing from upsampling without proper anti-aliasing filters
  • Snake activation producing harmonics that fold back into audible range
  • Out-of-distribution mel spectrograms (from LoRA-modified models) causing BigVGAN to extrapolate poorly
  • Instance normalization (in MelGAN) washing away pitch information
Fixes:
  • Anti-aliased activations (BigVGAN's AMP module)
  • Fine-tuning the vocoder on the actual mel spectrograms it will receive
  • STFT discriminator to penalize spectral artifacts directly
  • FA-GAN-style anti-aliased deconvolution modules

10. Fine-Tuning Pretrained Vocoders

Fine-tuning adapts a pretrained vocoder (trained on generic data by NVIDIA) to your specific use case. This is what we're doing — adapting BigVGAN v2 to handle mel spectrograms produced by our LoRA-modified DiT model.

Best Practices from the Literature

  1. Lower learning rate: Use 0.25–0.5× the from-scratch rate. BigVGAN from scratch uses 1e-4; we use 5e-5 for G.
  2. Match the mel pipeline: Generate mel spectrograms with your actual model (not ground-truth mels) as training data. We use "teacher-forced" data — running our DiT model at low noise (sigma=0.15) to produce mel spectrograms that match inference conditions.
  3. FreezeD: Freeze lower layers of the discriminator to preserve learned features while fine-tuning only the upper layers. Not always necessary if using a fresh discriminator (as we do with our STFT disc).
  4. D pre-training: Some approaches freeze G for the first few thousand steps and train only D, letting it adapt to the new data distribution. We found this provides marginal benefit in our setting.
  5. Differential learning rates: Apply higher LR to output layers, lower to backbone. In our e2e mode, decoder gets 1e-5 while vocoder gets 5e-5.
  6. Short fine-tuning: Pretrained vocoders need far fewer steps than from-scratch training. HiFi-GAN transfer learning: ~10K steps. Our fine-tuning: ~5K steps (15 epochs × 333 steps).
BigVGAN's universality: BigVGAN was specifically designed to generalize to out-of-distribution audio without fine-tuning. For many use cases, fine-tuning isn't necessary. We fine-tune because our LoRA-modified DiT produces subtly different mel spectrograms that push BigVGAN slightly OOD, causing metallic artifacts from the Snake activations.

The Problem We're Solving

When we apply LoRA adapters to the DiT for style transfer, the latent space shifts slightly. The VAE decoder converts these shifted latents to mel spectrograms that are subtly different from what BigVGAN was trained on. BigVGAN's Snake activations — which are tuned to specific frequency patterns — produce harmonic ringing when processing these slightly OOD mels.

  • Generated via "teacher forcing": run the DiT at low noise to produce mel spectrograms, paired with the corresponding ground-truth audio

12. Our Experiments: Discriminator Sweep & Results

The Problem: Discriminator Collapse

Our initial experiments used standard HiFi-GAN waveform discriminators (MPD + MSD, 8 sub-discriminators). After training, we discovered complete discriminator collapse:

MetricExpectedObservedDiagnosis
D(real)~0.8~0.5D outputs 0.5 for everything
D(fake)~0.2~0.5Maximum confusion
gap0.3–0.80.001Zero discrimination ability
d_loss per update0.5–2.04.08 sub-discs × (0.25+0.25) = 4.0

The math: With LSGAN and D outputting 0.5 for everything: each sub-discriminator contributes (0.5-1)² + (0.5)² = 0.25 + 0.25 = 0.5. With 8 sub-discriminators: 8 × 0.5 = 4.0. This is the "equilibrium trap" — D can't improve because real and fake look identical at the waveform level.

Interpretation

D is very strong — is that a problem? The discriminator has near-perfect accuracy (gap ≈ 1.0), d_loss ≈ 0, and g_adv ≈ 4.0 (maximum LSGAN penalty for 4 sub-discriminators). This is "D too strong" by classical GAN theory. However:

  1. Mel loss is still decreasing (0.6 → 0.32), meaning G is still improving. The mel/STFT reconstruction losses (weight 50) dominate over the adversarial loss (weight 1+2).
  2. The g_adv plateau at 4.0 is expected when D is near-perfect with LSGAN: (D(fake)-1)² ≈ (0-1)² = 1.0 per sub-disc × 4 = 4.0.
  3. Gradients still flow: Even though D's scores are saturated, the feature matching loss provides smooth gradients through D's intermediate layers.
What to watch: If mel loss stops decreasing while g_adv stays at 4.0, the adversarial signal has become pure noise (vanishing gradients through D). At that point, reducing D's learning rate or increasing G's learning rate would help. In our case, the cosine LR schedule will naturally reduce D's LR over time.

14. Hyperparameter Tuning Cookbook

Decision Tree: Which Discriminator?

Are artifacts visible in the waveform? │ ├── YES → Use MPD + MSD (standard HiFi-GAN setup) │ └── NO → Are artifacts visible in the spectrogram? │ ├── YES → Use STFT Discriminator or MRD │ │ │ ├── Harmonic artifacts → CQT Discriminator (log-freq) │ └── Broadband artifacts → Multi-Res STFT Discriminator │ └── NO → Artifacts may not be fixable with GAN training alone. Consider architectural changes (anti-aliasing, etc.)

Quick Fixes for Common Problems

ProblemDiagnosticFix
D collapse (gap < 0.05)D(r) ≈ D(f) ≈ 0.5Switch to spectral D, increase D LR, increase D/G ratio, remove R1
G explosion (mel spikes)mel jumps 2×+ suddenlyLower G LR, add gradient clipping, increase mel loss weight
D too strong (g_adv maxed)gap > 0.95, mel stalledReduce D LR, reduce D/G ratio, add spectral norm to D
Training oscillatesmel alternates up/downIncrease batch size, lower both LRs, add LR warmup
Metallic artifacts persistSpikes in high-freq spectrogramFine-tune vocoder on actual inference mels, use STFT disc

Hyperparameter Sensitivity Ranking

From most to least sensitive in our experiments:

  1. Discriminator domain (waveform vs. spectral) — BY FAR the most important. Switching to STFT disc changed gap from 0.001 to 0.917.
  2. D/G update ratio — 1:1 gave gap=0.19, 5:1 gave gap=0.92 with same disc.
  3. Spectral normalization on D — Removing it allowed D to learn in waveform domain, but caused G explosion.
  4. R1 gradient penalty — R1=10 fully suppressed D learning. R1=0 is fine with spectral norm.
  5. D learning rate — 4e-6 (too low for fine-tuning), 2e-4 (good), 1e-3 (would be too high).
  6. G learning rate — 5e-5 works well for fine-tuning. From-scratch BigVGAN uses 1e-4.
  7. Loss function — LSGAN vs. hinge had moderate impact. Hinge was too aggressive for our STFT disc.
  8. Loss weights — mel=45, fm=2, adv=1 are robust defaults from HiFi-GAN that work well.

VRAM ≈ 2 × (G_params + D_params) × bytes_per_param + batch_activations

In fp32 (4 bytes/param): 115M params = ~460 MB for weights, ×2 for gradients = 920 MB. Optimizer states (AdamW) add 2× more = 1.84 GB. Plus activations, intermediate tensors, and the discriminator. The decoder/e2e modes add the VAE decoder and its gradient-through computation.

16. Glossary of Terms

Activation Function — A nonlinear function applied element-wise after each neural network layer. Common ones: ReLU, LeakyReLU, Snake. Without nonlinearities, a neural network would be equivalent to a single linear transformation.
AdamW — An optimizer that maintains per-parameter learning rate adjustments using first and second moment estimates (mean and variance of gradients). The "W" means weight decay is decoupled from gradient updates. Standard choice for GAN training.
Adversarial Loss — The loss that comes from the GAN game: the generator is penalized when the discriminator correctly identifies its output as fake.
Aliasing — When a signal contains frequencies above half the sampling rate (Nyquist frequency), those frequencies "fold back" and appear as lower-frequency artifacts. In audio, this causes metallic/ringing sounds.
Anti-aliasing — Applying a low-pass filter before or after sampling to prevent aliasing. In BigVGAN, Kaiser-sinc filters are used around nonlinear activations to prevent harmonics from aliasing.
Batch Size — Number of training examples processed together. Larger batches give more stable gradient estimates but require more memory. GAN training benefits from larger batches (HiFi-GAN: 16, BigVGAN: 32).
Codec (Audio) — A system that encodes audio into a compressed representation and decodes it back. Neural codecs (EnCodec, SoundStream) use learned encoder/decoder networks with vector quantization.
Cosine Annealing — A learning rate schedule that follows a cosine curve from initial LR to a minimum. Gradually reduces the learning rate for fine-grained optimization in later training.
CQT (Constant-Q Transform) — Like STFT but with logarithmic frequency resolution (constant Q factor). Lower frequencies get better frequency resolution, higher frequencies get better time resolution. Matches human pitch perception.
D/G Update Ratio — How many discriminator training steps per generator step. 1:1 is standard. Higher ratios (5:1, 10:1) give D more time to learn, useful when D is weaker than G.
Discriminator Collapse — When the discriminator cannot distinguish real from fake data, outputting ~0.5 for everything. The adversarial loss becomes constant and provides no gradient signal to the generator.
Feature Matching Loss — L1 distance between intermediate feature maps of the discriminator for real and fake audio. Provides smoother, more stable gradient signal than the adversarial loss alone. Weight: λfm=2.
FFT (Fast Fourier Transform) — An algorithm that decomposes a signal into its frequency components. A time-domain waveform becomes a frequency-domain spectrum showing which frequencies are present and their amplitudes.
Fine-tuning — Starting from pretrained weights and continuing training on a specific dataset, typically with a lower learning rate. Much faster than training from scratch (thousands vs. millions of steps).
Generator — The neural network that produces synthetic data (in our case, audio waveforms). In a vocoder GAN, the generator IS the vocoder.
Gradient Clipping — Capping the maximum magnitude of gradients during backpropagation. Prevents training instability from gradient explosions. Typical values: 5.0 (aggressive) to 1000 (gentle).
Hinge Loss — A GAN loss formulation where the discriminator receives no further reward for pushing scores beyond ±1. Can be more stable than LSGAN but also more aggressive.
Hop Length — The step size (in samples) between consecutive STFT windows. Smaller hop = better time resolution but larger output. Typical: 256 samples at 16 kHz = 62.5 frames/second.
LSGAN (Least Squares GAN) — A GAN formulation using L2 (squared) loss instead of cross-entropy. D tries to make D(real)=1, D(fake)=0 using squared error. Provides smooth, non-saturating gradients.
Mel Scale — A perceptual frequency scale where equal distances correspond to equal perceived pitch differences. Warps linear frequency such that lower frequencies are more finely resolved (matching human hearing).
Mel Spectrogram — A time-frequency representation of audio using mel-scaled frequency bins with log-magnitude values. The standard intermediate representation for TTS systems.
Mode Collapse — When the generator converges to producing a limited set of outputs regardless of input. In audio, causes repetitive, buzzy, or frozen-sounding artifacts.
MOS (Mean Opinion Score) — Human-rated audio quality on a 1–5 scale (1=bad, 5=excellent). The gold standard for audio evaluation. UTMOS is an automated predictor of MOS.
MPD (Multi-Period Discriminator) — Reshapes 1D waveform into 2D with different periods {2,3,5,7,11} and applies 2D convolutions. Captures harmonic/periodic structure in audio.
MRD (Multi-Resolution Discriminator) — Operates on linear spectrograms at multiple STFT resolutions. Provides frequency-domain discrimination. Used in BigVGAN to replace MSD.
MSD (Multi-Scale Discriminator) — Three 1D CNNs at original, 2×, and 4× downsampled rates. Captures both fine and coarse temporal patterns.
n_fft — The FFT window size in samples. Larger = better frequency resolution but worse time resolution. Typical: 1024 samples.
n_mels — Number of mel frequency bins. More bins = finer frequency detail. Typical: 80 (HiFi-GAN), 100 (BigVGAN 24kHz), 128 (BigVGAN 44kHz).
Nyquist Frequency — Half the sample rate. The maximum frequency that can be represented without aliasing. At 16 kHz sample rate, Nyquist = 8 kHz.
PESQ (Perceptual Evaluation of Speech Quality) — An objective metric predicting perceived speech quality. Scores from -0.5 to 4.5 (higher = better). Requires a reference signal.
R1 Gradient Penalty — Regularization on the discriminator: R1 = λ · E[||∇D(real)||²]. Forces D to be smooth near real data points. Can prevent D from learning subtle differences if too high.
Segment Size — The length (in samples) of audio clips used during training. Longer segments give more context but use more memory. HiFi-GAN: 8,192, BigVGAN v2: 65,536.
Snake Activation — f(x) = x + (1/α)sin²(αx). A periodic activation function with learnable frequency α. Provides periodic inductive bias for modeling audio waveforms.
Spectral Normalization — Normalizing each layer's weight matrix by its largest singular value. Constrains the discriminator's Lipschitz constant, preventing it from becoming too "sharp" and destabilizing training.
STFT (Short-Time Fourier Transform) — Applies FFT to overlapping windows of a signal, producing a time-frequency representation. Parameters: n_fft (window size), hop_length (step size).
Transposed Convolution — A "reverse" convolution that upsamples (increases spatial/temporal resolution). Used in the generator to go from low-resolution mel (62 frames/sec) to high-resolution waveform (16,000 samples/sec).
UTMOS — University of Tokyo MOS. An SSL-based automated predictor of Mean Opinion Score for speech quality. Scores 1–5, restricted to 16 kHz audio.
VAE (Variational Autoencoder) — A model with encoder and decoder that maps data to/from a continuous latent space. In LTX-2.3, the Audio VAE's decoder converts latent vectors to mel spectrograms.
Vocoder — A model that converts a mel spectrogram (or similar intermediate representation) into an audio waveform. The final stage of a TTS pipeline.
