Diff-vectors — which LoRA maximizes / minimizes each emotion

Report (plain English)

Idea. A diff vector only needs a difference. For every emotion dimension we ask: which LoRA pushes it up the most, and which pushes it down the most (compared with the base model on the same prompt). Those two give a max/min LoRA pair whose outputs differ maximally along that emotion — e.g. if a Sexual-Lust LoRA happens to lower Concentration, then (base − SexualLust) is a 'more concentrated' direction.

How measured. effect(LoRA, dim) = mean EmoNet score of that dim at LoRA-strength 100% minus at 0%, same neutral utterances, prompt and seeds. Green = the LoRA raises that dimension, red = lowers it.
